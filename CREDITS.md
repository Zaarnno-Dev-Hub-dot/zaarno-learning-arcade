# Credits

Everything in this repository is original work, released under the MIT license (see [LICENSE](LICENSE)).

- **Art:** every character, tile and background is drawn in code, with canvas shapes and small pixel-art
  strings inside each HTML file. No sprite sheets, image files or artwork from other games are used.
- **Sound:** generated live with the Web Audio API. There are no audio files.
- **Fonts:** system fonts only (Trebuchet MS, Verdana, Segoe UI and their fallbacks).
- **Inspiration:** Plumber Typing follows the classic "type the word to stop the enemy" typing-game format.
  MathMan follows the classic maze-chase arcade format. Their names, characters, mazes, levels and word
  lists are original to this project.
- **Screenshots** in `docs/screenshots/` are generated from the games themselves with
  `tools/capture-screenshots.mjs`.
